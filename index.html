Agent Platform

While Review Bot catches problems before they merge, the Agent Platform goes a step further: it autonomously plans, implements, and validates changes in a sandboxed environment — grounded in the same RAG context, governed by the same rules.

Plan → Execute → Validate loop

The agent starts with a task prompt, estimates complexity (low / medium / high), and dynamically allocates a step budget. It then writes files, runs validations, and calls complete() only when all checks pass — producing a structured commit with branch name, title, and body.

RAG-grounded execution

Every agent run has access to a RAG query interface. Before writing code, the agent retrieves relevant internal documentation, architectural decisions, and coding standards — ensuring generated code respects your organization's conventions and constraints, not just general best practices.

Full auditability — step by step

Every tool call, file write, and decision is captured as a typed AgentStep. Each step records its token usage and USD cost, giving you a complete trace from task to commit — suitable for post-hoc review or compliance reporting.

FAQ

The practical questions everyone asks before they let a bot comment on — or write — production-critical code.

How do you reduce hallucinations? ▾
Both the Review Bot and Agent Platform are diff-first and RAG-grounded. Rather than generating context from scratch, they retrieve targeted information from your actual codebase and internal docs. Findings include confidence markers and explicit "what to verify" notes when retrieved context may be incomplete.
Can it enforce our internal ADRs and policies? ▾
Yes. Eolentis ingests organization-specific sources (coding guidelines, ADRs, compliance docs) into the RAG layer. Both the Review Bot and Agent Platform query this knowledge base at runtime, and map findings or actions back to those sources to support governance and auditability.
Does it run behind VPN or fully on-prem? ▾
Yes. We support on-prem / behind-VPN deployments, including RAG running entirely within your network perimeter. We can align the setup to your environment constraints during the pilot.
What does a pilot look like? ▾
Typically: (1) connect 1–2 repos, (2) ingest key guidelines/ADRs into the RAG layer, (3) run the bot on real PRs, (4) review measured outcomes like cycle time and policy violations caught pre-merge.
What can the Agent Platform actually do? ▾
It takes a task description, plans an implementation, retrieves relevant context via RAG, writes and validates code in a sandbox, then produces a structured commit ready to open a PR. It can ask clarifying questions mid-run and provides full per-step cost visibility. Agent-generated PRs are then reviewed by Review Bot automatically.
Will this replace human reviewers or engineers? ▾
No. Review Bot reduces bottlenecks by handling routine governance checks consistently. The Agent Platform handles well-scoped implementation tasks, not architectural decisions. Humans keep ownership of final approval, direction, and anything that requires judgment beyond what the RAG-grounded context can resolve.
